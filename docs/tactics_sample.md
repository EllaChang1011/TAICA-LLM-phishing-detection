# 招數清單：讀信工作檔

## 怎麼用

1. 一封一封讀，看每封下面的「草稿分類」。
2. 同意就跳過；不同意就在「你的判斷」寫上你的分類。
3. 覺得某封信用了清單裡沒有的招數，就在「你的判斷」寫下新招數的名字。
4. 讀完後回答最下面的 3 個問題。

## 草稿分類（誘餌）

| # | 誘餌 | 說明 |
|---|---|---|
| 1 | 帳號到期 | 帳號或密碼快到期、快被停用 |
| 2 | 安全警告 | 偵測到異常登入或可疑活動 |
| 3 | 帳單付款 | 扣款失敗，要你更新付款資料 |
| 4 | 包裹運費 | 包裹卡住，要補運費 |
| 5 | 檔案分享 | 有人傳檔案給你，要你點開 |
| 6 | 發票催款 | 發票逾期，要你付款 |
| 7 | 利誘 | 退稅、投資、優惠、工作、免費資源 |
| 8 | 慈善捐款 | 以捐款為名要你付錢 |
| 0 | 沒有可疑招數 | 給正常信用 |

1. 有沒有哪些類別應該合併？（例如 1 和 2 都是「你的帳號出事了」）
2. 有沒有讀到清單裡沒有的招數？
3. 除了「誘餌」，要不要另外標「手法」（假冒身分、製造急迫感、要你點連結、要你交出資料）？

## 驗證紀錄：新抽的信能不能歸進現有類別

### 第 2 輪（20 封，seed=7）

- 17 封能歸類
- 3 封是新招數 → **新增類別 9「信箱錯誤」**：說你有郵件卡住、收不到，要你重新登入
  - idx 1296、1607、2192

### 第 3 輪（20 封，seed=99，已加入類別 9）

- 17 封能歸類（類別 9 又出現 2 次：idx 1570、997）
- 待決定：
  - idx 2016：「你有逮捕令，點連結避免被捕」→ 現有類別都不合，可能要新增「法律恐嚇」
  - idx 1664、903：朋友分享「秘訣」「文章」，不算利誘，比較像好奇心 → 類別 7 要不要改成「利誘／好奇」
  - idx 2978：感謝對方付款，看不出問題 → 0（跟 #24 一樣，可能是標籤錯誤）

### 觀察

- LLM 寫的「發票」類信件裡，有些只是正常的感謝付款信（#24、idx 2978），標籤卻是 phishing
- 有些信沒有連結，而是要你直接回信提供資料（idx 172、957 中獎信；#25 催款信）
